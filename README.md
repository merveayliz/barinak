# 🐾 Yuva Ol - Barınak ve Sahiplendirme Platformu

Bu proje, sahipsiz hayvanların sesini duyurmak ve potansiyel sahipleriyle buluşturmak amacıyla tasarlanmış, kullanıcı dostu ve modern bir web platformudur. 

## ✨ Özellikler
* **Dinamik Logo:** Harflerin üzerinden geçen ve kullanıcı etkileşimiyle zıplayan interaktif köpek animasyonu.
* **Canlı İstatistikler:** Barınaktaki hayvan sayısı, konum ve günlük mama durumu gibi verilerin takibi.
* **Akıllı Filtreleme:** Dostlarımızı yaş ve cinsiyete göre anlık olarak filtreleyebilme özelliği.
* **Favori Sistemi:** Beğenilen dostlarımızı `localStorage` kullanarak tarayıcıya kaydetme.
* **Tam Mobil Uyumluluk:** Her ekran boyutunda (Telefon, Tablet, PC) sorunsuz çalışan duyarlı (responsive) tasarım.

## 🛠 Kullanılan Teknolojiler
* **HTML5:** Yapısal düzen ve içerik yönetimi.
* **CSS3:** Modern grid sistemleri, animasyonlar ve mobil uyumlu sorgular (Media Queries).
* **JavaScript (Vanilla):** Filtreleme mantığı, favori sistemi ve DOM manipülasyonu.

## 🚀 Kurulum ve Çalıştırma
Projenin en güncel halini yerel bilgisayarınızda çalıştırmak için:
1. Depoyu klonlayın: `git clone https://github.com/kullanici-adin/depo-adin.git`
2. `index.html` dosyasını tarayıcınızda açın veya VS Code **Live Server** eklentisini kullanın.
